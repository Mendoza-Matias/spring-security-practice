<h1 align="center">register-of-users</h1>

---

<div align="justify">
  <p>
    This is a project created with the objective of practicing Spring Security and understanding as  how authentication and authorization work in a web application.
  </p>

  <p>
    The application implements a registration and login system connected to a frontend developed with Angular. Authentication is done with JWT, using an access token to access protected resources and a refresh token stored in an HttpOnly cookie for renewing the session in a more secure way.
  </p>

  <p>
    The backend is organized by layers and uses DTOs to separate the API contracts from the persisted entities. It also features data validation, authorization based  on roles, public and protected routes, CORS configuration and global error handling.
  </p>

  <p>
    The main purpose of the project is to serve as a learning foundation and reference for future applications that require authentication, access control, and session management.
  </p>
</div>
